# Portfolio Copy Voice Guide

## Goal
- Keep EN/ES copy aligned with a high-value enterprise software development profile.
- Prioritize clarity, ownership, and measurable outcomes over decorative language.

## Core Tone
- Confident, direct, and specific.
- Technical but business-aware.
- Evidence-first and interview-ready.

## Messaging Priorities
1. Role clarity (who you are).
2. Scope ownership (what you lead end-to-end).
3. Business outcomes (what changed, with metrics when possible).
4. Execution quality (maintainability, delivery reliability, communication).

## Approved Topbar Pattern
- Title: role + domain + seniority signal.
- Subtitle: one-line value proposition focused on outcomes.
- Proof pills: max 2 on mobile, 3 on desktop; each under 6 words when possible.

## Preferred Vocabulary
- EN: ownership, delivery, outcomes, reliability, execution, scope, maintainable, measurable.
- ES: responsabilidad, entrega, resultados, confiabilidad, ejecucion, alcance, mantenible, medible.

## Avoid
- Generic claims: "passionate", "hardworking", "creative" without evidence.
- Long topbar text that wraps into multiple lines.
- Too many claims in one sentence.
- Mixing tones (casual + corporate) in the same section.

## EN/ES Consistency Rules
- Keep semantic equivalence, not literal translation.
- Preserve hierarchy: title > subtitle > proof signals.
- If EN uses outcome language, ES must also use outcome language.
- Keep all code identifiers and class names in English.

## Quick QA Checklist
- Can a hiring manager understand your value in 10 seconds?
- Does each line communicate role, scope, or outcome?
- Are proof pills short, concrete, and non-overlapping?
- Does the wording sound credible for enterprise/B2B roles?
